Perfil de Puesto: "Analista de Sistemas" (Modelo Oficial del Manual de Perfil de Puestos - MPP)

Desarrollo completo del cargo conforme a los 8 apartados del Manual de Perfil de Puestos, con casillas de verificación (☑ / ☐) y marcaciones con "X".

Manual de Perfil de Puestos (MPP) — Ficha Técnica del Puesto

Estructura formal de identificación, misión, funciones, coordinaciones, requisitos y competencias.

Nivel Organizacional 3
Puesto: Analista de Sistemas
1. IDENTIFICACIÓN DEL PUESTO Apartado 1 de 8
Unidad orgánica: Departamento de Sistemas y Tecnologías de Información
Nivel Organizacional: Nivel Organizacional 3 Nombre del puesto: Analista de Sistemas
Dependencia Jerárquica Lineal: Gerencia de Administración y Finanzas
Dependencia Jerárquica Funcional: Jefe del Departamento de Sistemas y Tecnologías de Información
Puestos que supervisa: Asistente de Informática / Practicantes de Sistemas
2. MISIÓN DEL PUESTO Apartado 2 de 8
"Analizar, diseñar, modelar y validar los requerimientos funcionales y técnicos de los sistemas de información y bases de datos institucionales, asegurando la optimización de los procesos operativos y administrativos, la calidad del software y el alineamiento con los objetivos estratégicos de la entidad."
3. FUNCIONES DEL PUESTO Apartado 3 de 8
N° FUNCIONES
1 Realizar el levantamiento, análisis y validación de requerimientos funcionales y no funcionales con las unidades orgánicas usuarias para el desarrollo o mejora de los sistemas de información institucionales.
2 Efectuar el modelamiento de procesos de negocio y sistemas utilizando el Lenguaje Unificado de Modelado (UML) y diagramas Entidad-Relación (DER) para estructurar soluciones informáticas escalables.
3 Diseñar la arquitectura de software de las aplicaciones institucionales, definiendo componentes lógicos, capas de aplicación, estándares técnicos y patrones de diseño.
4 Elaborar las especificaciones detalladas de casos de uso, historias de usuario, prototipos de interfaz (wireframes) y matrices de trazabilidad de requerimientos.
5 Diseñar, normalizar y optimizar estructuras de bases de datos relacionales (SQL), definiendo tablas, vistas, índices, procedimientos almacenados y reglas de integridad referencial.
6 Planificar y ejecutar pruebas de aseguramiento de calidad del software (QA), verificando el cumplimiento de casos de prueba funcionales, de integración y de aceptación del usuario.
7 Elaborar y mantener actualizada la documentación técnica y funcional de los sistemas (manuales de arquitectura, diccionarios de datos, guías de instalación y manuales de usuario).
8 Brindar capacitación técnica y funcional a los usuarios finales y al personal de soporte durante el despliegue y puesta en producción de nuevos módulos o sistemas.
9 Diseñar y especificar mecanismos de integración de sistemas mediante servicios web (APIs REST / SOAP) para garantizar la interoperabilidad entre plataformas internas y externas.
10 Evaluar el desempeño operativo y la seguridad aplicativa de los sistemas en producción, proponiendo mejoras evolutivas y mantenimientos correctivos.
11 Apoyar en lo que le compete respecto a la implementación y evaluación del Plan Estratégico Institucional.
12 Otras funciones inherentes al cargo, dispuestas por el Jefe superior inmediato.
4. COORDINACIONES PRINCIPALES Apartado 4 de 8
Coordinaciones Internas: Jefe del Departamento de Sistemas y Tecnologías de Información y todas las Unidades Orgánicas usuarias.
Coordinaciones Externas: Proveedores de servicios tecnológicos, entidades públicas y privadas vinculadas a interoperabilidad.

Perfil 02 · Formato de Ficha Ágil Tecnológica (Tech Role Canvas)

Desarrollador de Software Full Stack / Backend

1. Propósito Operativo en el Equipo de Ingeniería

Diseñar, codificar, integrar y desplegar aplicaciones web multicapa y servicios de backend transaccionales, traduciendo la arquitectura lógica y las historias de usuario en software seguro, mantenible y de alto rendimiento.

Adscripción: Equipo de Desarrollo de Software  ·  Metodología: Marco Ágil Scrum e Integración Continua
2. Stack Tecnológico (Insignias Técnicas)
Java (Spring Boot / Jakarta EE) C# (.NET Core / Web API) HTML5 / CSS3 / JavaScript SQL (SQL Server / PostgreSQL) Git (GitHub / GitLab)
3. Responsabilidades Clave de Desarrollo
  • Arquitectura Backend: Programar lógica de negocio, microservicios y APIs RESTful con Java y C# aplicando principios SOLID.
  • Interfaces Frontend: Construir vistas web semánticas, responsivas y accesibles empleando HTML5, CSS3 y JavaScript moderno.
  • Persistencia Relacional: Desarrollar consultas SQL optimizadas, transacciones, vistas e integración mediante frameworks ORM.
  • Control de Versiones: Administrar ramas de código, fusiones (merge requests) y revisiones de pares usando Git.
  • Seguridad Aplicativa: Implementar autenticación segura (JWT/OAuth) y mitigar riesgos del estándar OWASP Top 10.
4. Entregables Verificables del Puesto
  • Módulos de Software en Producción: Código fuente limpio, compilado y sincronizado en el repositorio institucional Git.
  • Especificación de APIs: Contratos de servicios REST documentados bajo estándar OpenAPI / Swagger.
  • Scripts de Base de Datos: Paquetes DDL y DML versionados para creación y migración de esquemas SQL.
  • Suite de Pruebas Unitarias: Pruebas automatizadas ejecutadas sobre las reglas críticas del negocio.
  • Instructivo de Despliegue: Guía técnica de configuración de entorno, variables y compilación para pase a producción.
5. Indicadores de Desempeño (KPIs de Ingeniería)
≥ 90% Entregas por Sprint
Cumplimiento de historias de usuario comprometidas en cada iteración.
≥ 80% Cobertura de Pruebas
Porcentaje de lógica de negocio cubierta por pruebas unitarias.
< 5% Estabilidad en Pase
Tasa máxima de defectos o regresiones tras el despliegue a producción.
0 Críticas Seguridad de Código
Cero vulnerabilidades de severidad alta en auditoría de código estático.
6. Requisitos Exigidos
  • Formación: Titulado Técnico o Universitario en Desarrollo de Sistemas de Información, Ingeniería de Sistemas o Computación.
  • Experiencia: Mínimo 2 años en construcción de aplicaciones web o servicios empresariales con Java, C# y SQL.
  • Especialización: Desarrollo de Software Empresarial, Arquitectura de Aplicaciones Web o Metodologías Ágiles.
Perfil 03 · Formato de Matriz por Competencias y Niveles de Criticidad

Administrador de Bases de Datos (DBA)

1. Objetivo Operacional del Cargo

Asegurar la continuidad operativa ininterrumpida, integridad transaccional, seguridad perimetral y rendimiento óptimo de los motores de bases de datos institucionales, ejecutando estrategias preventivas de respaldo, recuperación ante desastres (DRP) y gobierno de datos.

2. Entorno Tecnológico Administrado

Motores RDBMS: Microsoft SQL Server, PostgreSQL, MySQL / MariaDB y Oracle Database.
Plataformas y Herramientas: Servidores Linux y Windows Server, herramientas ETL (SSIS), utilitarios de respaldo (RMAN / pg_dump), auditoría TDE y monitoreo de rendimiento.

3. Matriz de Responsabilidades Críticas y Acuerdos de Nivel de Servicio (SLA)
Dominio de Competencia Nivel de Criticidad Responsabilidades Operativas Críticas Mecanismos Técnicos Métrica / SLA
1. Copias de Respaldo y Recuperación (Backups) Crítica · Nivel 1 Planificar, automatizar y auditar políticas de respaldos completos, diferenciales y de logs transaccionales. Ejecutar simulacros periódicos de restauración para garantizar la recuperación ante contingencias. Jobs programados, cifrado de respaldos y replicación en almacenamiento externo. RPO < 15 min
RTO < 1 hora
2. Seguridad y Control de Accesos Crítica · Nivel 1 Aplicar el principio de mínimo privilegio, gestión de roles, cifrado transparente de datos (TDE), enmascaramiento de información sensible y auditoría de transacciones críticas. Políticas DCL (GRANT/REVOKE), cifrado SSL/TLS y trazabilidad de auditoría. 0 Brechas de seguridad
3. Optimización de Consultas (Tuning SQL) Alta · Nivel 2 Analizar planes de ejecución de consultas pesadas, resolver bloqueos transaccionales (deadlocks), desfragmentar índices y actualizar estadísticas del motor relacional. Execution Plans, índices Clustered / Non-Clustered y particionamiento de tablas. Respuesta < 200 ms
4. Migración de Datos y Procesos ETL Alta · Nivel 2 Diseñar y ejecutar procesos de extracción, transformación y carga (ETL), migración controlada entre versiones o motores de bases de datos y conciliación de integridad post-migración. Paquetes SSIS, scripts de validación y carga masiva transaccional. 100% Integridad referencial
5. Alta Disponibilidad y Capacidad Media-Alta · Nivel 3 Supervisar el crecimiento de almacenamiento (datafiles / tablespaces), configurar esquemas de replicación o clústeres de conmutación y aplicar parches de seguridad. Clústeres de alta disponibilidad, replicación sincrónica y alertas tempranas. 99.95% Uptime anual
4. Perfil Técnico Requerido para el Administrador de Bases de Datos
Formación Académica: Titulado Profesional Técnico o Universitario en Desarrollo de Sistemas de Información, Ingeniería de Sistemas, Computación e Informática o carreras afines.
Conocimientos Técnicos: Dominio avanzado de SQL estándar, T-SQL y PL/pgSQL; arquitectura interna de motores relacionales (memoria, transacciones ACID, control de concurrencia); administración de servidores Linux/Windows y scripting de automatización.
Especialización: Programas de especialización o certificaciones en Administración de Bases de Datos (SQL Server, PostgreSQL u Oracle), Seguridad de la Información o Gestión de Servicios TI (ITIL).
Experiencia Requerida: Mínimo 3 años de experiencia general en el área de TI y 2 años de experiencia específica en administración de motores de bases de datos relacionales o arquitectura de datos.
Competencias Personales: Rigor analítico, ética profesional en el resguardo de información confidencial, tolerancia a la presión operativa y orden metodológico.
